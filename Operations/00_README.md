## What This Folder Is

This is **how verbAfrica actually runs day-to-day**. The Strategy folder says *what* we're doing and *why*. This folder says *how*.

The docs here are written to be **executable** — someone reading them should know what to do, in what order, with what tools. They are living documents — update them whenever reality diverges from what's written.

## The Workflow

**Every booking is a learning opportunity.** During the beta, the Booking Playbook is the *current best understanding* — it changes as we discover things.

**After every booking** — open the playbook, ask: did reality match this? If not, update it.

**During weekly check-in** — review Response Standards: are we hitting our internal targets? If we're missing one consistently, either change the target or change how we work.

**Anything operationally meaningful** — log to `Journey/Storyline.md` so future-us understands how the playbook evolved.
