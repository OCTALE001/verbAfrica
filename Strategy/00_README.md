# Strategy

*Maintained by Alexander October + Claude | Started June 2026*

---

## What This Folder Is

This is where the **direction** of verbAfrica (and the company behind it) lives. Not what we know about the world — that's in `verbAfrica Research/`. Not how we run the day-to-day — that's in `Operations/`. This is the *"what are we doing and why"* folder.

These are **living documents**. They change as we learn. Stale strategy is worse than no strategy.

---

## Documents in This Folder

| File | What It Is | When to Read |
|------|-----------|--------------|
| `01_Vision.md` | The North Star — the company, why booking admin first, what success looks like, what we're *not* doing | Before any product, hiring, or messaging decision. Re-read monthly. |
| `02_Roadmap.md` | Current phase, what's next, open questions, running decisions log | Weekly. Whenever a decision is made, log it here. |

---

## The Workflow

**Once a week** (15 min with Claude):
- Bring any decisions you've been thinking about
- Bring any signals from the beta (creative feedback, client behaviour, booking outcomes)
- Update `02_Roadmap.md` — move the current-phase marker, add to the decisions log, add/answer open questions

**When something big changes** (a major insight, a pivot, a new commitment):
- Update `01_Vision.md` and date the change at the bottom
- Make sure the rest of the docs in this folder still hold up

**Before any major decision** (investment, hire, big spend, public commitment):
- Re-read `01_Vision.md` first
- Check that the decision serves it
- If it doesn't — either the decision is wrong, or the vision needs updating. Both are valid answers.
